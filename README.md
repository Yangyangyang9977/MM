# 山姆图文购物车 · GitHub Pages 静态版

包含三张原清单的86款商品、价格与86个本地图片文件。默认每款1件。按11月3日、5日、6日分页，另可查看全部商品。全部各1件的校验金额为7608.20元。

## 先在电脑上使用

解压整个文件包后，双击 `index.html`。请保留 `images` 文件夹和其他文件的相对位置。也可直接使用另附的单文件离线HTML，无需安装任何软件。

## 上传到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `sams-cart`。没有支持私有 Pages 的套餐时，请使用公开仓库。
2. 上传解压后的所有文件和 `images` 文件夹到仓库根目录。必须让 `index.html` 直接出现在根目录，不能再套一层文件夹；不要只上传 ZIP。保留图片文件夹的层级。
3. 打开仓库 `Settings → Pages`。
4. 在 `Build and deployment → Source` 选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/(root)`，然后保存。若实际分支名不同，选择你上传文件所在的分支。
6. 等待 Pages 构建完成，打开该设置页面给出的网址。普通项目仓库的网址形式为 `https://你的用户名.github.io/仓库名/`。

本站没有构建步骤，不依赖 Node.js、外部字体、登录、Sites 域名或图片外链。所有页面资源都使用相对路径，支持项目仓库子路径。`.nojekyll` 是空文件，用于禁用 Jekyll 处理；部分上传界面不会显示这个隐藏文件，其他资源不依赖它。

## 怎么计算

- 单项小计 = 单价 × 数量，只在商品已勾选且数量大于0时计入。
- 顶部总价、分类合计、日期合计均只统计已选商品。
- 切换日期和搜索只影响当前列表，总价始终统计所有日期的已选商品。
- “排除当前结果”只取消当前搜索与日期筛选中商品的勾选，不删除商品。
- 默认各1件；可以直接输入数量，也可以用加减按钮。

## 后续添加更多商品

点击“添加商品”，填写名称规格、单价、数量、日期、类别，可上传本地照片。新日期、新类别会自动出现在页面中。照片只保存在当前浏览器，不会上传到服务器。

数量、勾选和新增商品存储在当前浏览器。**浏览器里的新增商品不会自动改写 GitHub 仓库，也不会同步到他人的电脑或手机。** 更换设备、浏览器或网址前，点击“备份购物车”，在新页面点击“导入购物车备份”；备份包含新增商品、照片、数量与勾选状态。导入会提示确认，并替换当前内容。清空浏览器站点数据会删除本机保存的调整。

如果想让所有访客都能看见新增商品，需把它加入 `data.js` 的相应日期数组，格式为 `["商品名称及规格", 单价, "类别"]`。新商品的序号按当日数组位置自动生成；给该商品在 `images.js` 中添加对应条目，如 `"11月7日-1": {"file":"images/new-photo.jpg","source":"原图片来源网址","note":""}`，同时上传照片。`images.js` 的键由日期和当日序号组成。发布后现有商品的日期和序号不要重排，否则会影响已有浏览器的数量记录。新日期宜添加在数组末尾。

## 导出

- 已选CSV：只导出已选且数量大于0的商品，含分类和日期汇总。
- 全部CSV：包含原有和新增商品、数量、勾选状态；合计仍只计算已选商品。
- 购物车JSON备份：用于恢复，不是发布文件。
- 打印/PDF：打印当前日期和搜索结果，排除项不打印；右侧汇总仍是整个购物车的已选汇总。
